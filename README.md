# Abdelrhman Saad: Portfolio

React + Vite + Tailwind CSS v4.

```bash
npm install
npm run dev      # local
npm run build    # production build in dist/
```

## Where to edit
- `src/data/profile.js`: contact info (add your LinkedIn URL here)
- `src/data/skills.js`: skill groups
- `src/data/featured.js`: real-world projects (add `live` / `github` links)
- `src/data/experience.js`: experience and education
- `src/data/learning.js` + `src/assets/projects/`: learning projects and screenshots

## Deploy
Vercel / Netlify: import the repo, build command `npm run build`, output `dist`.
GitHub Pages: the build already uses relative paths, so upload the contents of `dist/`.
